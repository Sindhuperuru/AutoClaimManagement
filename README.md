\# AutoClaimManagement – Auto Insurance Claim Management System



\## Project Overview

AutoClaimManagement is a web-based application designed to manage the auto insurance claim process. It helps customers submit claims and allows insurance staff to review, process, and manage claim requests.



\## Features

\- Customer claim submission

\- Insurance claim management

\- Claim review and approval workflow

\- Role-based access for different users

\- BPMN-based workflow automation

\- DMN-based decision management



\## Technologies Used

\- \*\*Backend:\*\* Java, Spring Boot

\- \*\*Frontend:\*\* React, Vite

\- \*\*Workflow Automation:\*\* Camunda BPMN and DMN

\- \*\*Build Tool:\*\* Maven



\## Project Structure

\- `backend/` – Backend application

\- `frontend/` – Frontend application

\- BPMN and DMN files – Workflow and decision models



\## How to Run



\### Backend

Run the following command from the project directory:



```cmd

start\_backend.bat

```



Backend URL: http://localhost:8080



\### Frontend

Run:



```cmd

start\_frontend.bat

```



Frontend URL: http://localhost:3004
